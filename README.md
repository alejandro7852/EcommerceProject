# EcommerceProject
E-commerce desarrollado con ASP.NET Core MVC y .NET 9.

## Tecnologías

- C#
- .NET 9
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Transbank Webpay
- Bootstrap
- JavaScript

## Funcionalidades

- Registro e inicio de sesión
- Catálogo de productos
- Carrito de compras
- Gestión de órdenes
- Sistema de estados de órdenes
- Integración con Webpay
